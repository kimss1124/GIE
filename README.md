## 🚀 웹사이트(`index.html`) 주요 구현 기능

1. **아이덴티티 & 브랜딩:**
   * 슬로건: *"측정 데이터와 문서 업무는 AI로 줄이고, 엔지니어의 현장 판단을 강화합니다."*
   * 원칙: *"AI는 분석·초안, 전문 기술인력은 계측·조정·최종 책임 (Human-in-the-Loop)"*
2. **AS-IS vs TO-BE 비교 섹션:**
   * 수천 개 계측값 문서화 공수 40% 낭비 vs AI 자동 파싱 및 60% 절감
   * 담당자 개인 PC 분산 노하우 vs 사내 AI 지식베이스 통합
3. **4대 핵심 사업 분야 명시:**
   * 기계설비설계 1차 검수 / TAB·Commissioning / 기계설비 법정 성능점검 / 엔지니어링 영업 지원
4. **3단계 철저한 검증 프로세스 및 보안 통제:**
   * 01.데이터 준비 ➜ 02.AI 분석 & 기준 대조 ➜ 03.엔지니어 최종 승인 및 서명
   * 내부 폐쇄 보안망, 접근 제어, 데이터 암호화, 책임자 서명제
5. **실시간 인터랙티브 [TAB 계측 이상감지 및 보고서 초안 생성 시뮬레이터]:**
   * 측정 항목(온도, 풍량, 압력)과 기준치, 실측치를 입력하고 [AI 진단 실행] 클릭
   * 허용 오차 초과 구간 시각화 차트 및 AI 원인/조치 의견 즉시 출력
   * **[정식 보고서 초안(PDF 양식) 확인하기]** 클릭 시 엔지니어 서명이 들어간 공인 보고서 모달 출력
6. **정량적 성과 및 6개월 로드맵:**
   * 16h ➜ 6h 공수 절감, 오류율 0%대, 대응 속도 3배 향상 지표
   * Stage 1(1~4개월) 파일럿 ➜ Stage 2(5~6개월) 확산 ➜ Stage 3(6개월 이후) 전사 운영
7. **온라인 기술 상담 및 프로젝트 문의 폼:**
   * 발주처 문의 접수 및 자동 응답 시뮬레이션
